Overview

Keeping water conditions easier to understand.

CrayTech is an Android-based IoT solution developed for modern crayfish farming. The system continuously monitors water quality parameters and provides real-time updates through a mobile application while supporting automated feeding operations. By integrating environmental monitoring, cloud-based data management, and feeding automation, CrayTech helps farmers make informed decisions, maintain optimal growing conditions, and improve overall farm productivity.

Problem

Crayfish farming needs consistent monitoring because sudden water quality changes can affect production and animal health.

Solution

The app connects sensor readings with a mobile interface so users can review current conditions and respond faster.

Outcome

The project presents a practical monitoring workflow with screens, alerts, and cloud-connected data handling.
