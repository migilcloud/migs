Task Management System

A full stack productivity app with secure JWT authentication, user-specific task management, and a refreshed teal interface — powered by React, FastAPI, and Neon Postgres.

Live Website GitHub
Role Full Stack Developer
Frontend React + Vite
Backend FastAPI
Database Neon Postgres

Overview

Managing tasks through a modern full stack application.

The Task Management System lets users register, sign in securely, and manage personal tasks with full CRUD support. The latest update refreshed the UI with a cleaner teal design and moved the backend to free-tier cloud hosting on Render with Neon Postgres, while the frontend stays on Vercel.

Problem

Users need a simple way to organize tasks, monitor progress, and manage work efficiently across devices.

Solution

Built a secure task app with JWT auth, REST APIs, SQLAlchemy models, and a polished React interface for creating, updating, completing, and deleting tasks.

Outcome

Shipped a live full stack app with a refreshed UI and a sustainable free hosting setup on Vercel, Render, and Neon.

Technology

Tools Used

React Vite FastAPI PostgreSQL SQLAlchemy JWT Authentication Axios REST API

Features

Key functionality

User Authentication

Secure registration and login with JWT-based auth so each user only sees their own tasks.

Task Management

Create, update, complete, and delete tasks through a clean dashboard with a refreshed teal UI.

Cloud-Ready Backend

FastAPI API hosted on Render, connected to Neon Postgres, with health checks and CORS configured for the Vercel frontend.
